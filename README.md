Project Overview
Manages records of pets available for adoption, allowing addition, updating, and removal of pet profiles.
This program is a simple tool for pet shelter staff to keep track of animals. You can add new pets, change their information, delete records, or see a full list of all animals in the shelter.

Main Features
Pet Management: You can create, read, update, and delete (CRUD) pet records.
GUI: The program has windows and buttons, so you don't need to use the command line.
Database: All information is saved in a SQLite database so the data stays safe even after closing the app.
Login System: There is a login screen with two roles: Admin and User.
Data Validation: The program checks if names and ages are entered correctly to prevent errors.
OOP Principles: I used inheritance (Classes for Dog, Cat, and Parrot) and polymorphism in the code.

Challenges
The hardest part was managing the "talking" feature for parrots. At first, I tried to save everything in one text line, but it caused many bugs. I solved this by changing the database structure and adding a special column for the parrot's speech status. Now the data is clean and works perfectly without much additional code for talking for parrots.
